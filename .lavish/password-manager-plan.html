Local-First Password & Clipboard Sync

A robust, offline password manager and universal clipboard syncing securely between laptop and phone.

Offline P2P Bluetooth Universal Clipboard

The Goal

  • Absolute privacy: No cloud hosting or third-party servers.
  • Seamless sync: Laptop and phone stay in sync automatically when in proximity.
  • Universal Clipboard: Copy text or photos on one device, paste on the other (Windows Phone Link style).

Core Challenges

  • Secure key exchange over local networks/Bluetooth without a trusted third party.
  • Handling conflict resolution when passwords are edited offline on both devices.
  • Transferring large payloads (photos via clipboard) over Bluetooth Low Energy vs Wi-Fi Direct.

Implementation Approach

1. Connectivity & Transport Layer

Since Bluetooth LE has low bandwidth, we will use a hybrid approach:

  • Discovery: Bluetooth Low Energy (BLE) to detect when devices are near each other.
  • Transport: Upgrade to Wi-Fi Direct (or local LAN) automatically when transferring large clipboard items (photos). For tiny password syncs, BLE is sufficient.
2. Encryption & Key Exchange

Zero-trust architecture for local connections:

  • Initial pairing via QR code (sharing public keys).
  • All data over BLE/Wi-Fi is encrypted using ChaCha20-Poly1305.
  • The local vaults are encrypted at rest using AES-256-GCM derived from a master password (Argon2id).
3. Universal Clipboard Service

Background services on both platforms:

  • Windows: C# or Rust background daemon using Win32 Clipboard APIs.
  • Android Phone: Android Accessibility Service to monitor clipboard changes.
  • Images are compressed to JPEG/WEBP before transmission to ensure fast transfers.

Risks & Open Questions

Risk / Question Impact Proposed Mitigation
Conflict Resolution Medium Implement CRDTs (Conflict-free Replicated Data Types) for merging vault changes deterministically based on logical clocks/timestamps.
Battery Drain Medium Use BLE advertising only on phone unlock or clipboard change events, rather than constant polling.

Potential Improvements & Roadmap

  • Browser Extension
  • Android Autofill
  • PIN Unlock
1
Windows Browser Extension: Companion extension (Chrome/Firefox/Edge) that talks to the local background daemon to securely autofill passwords without leaving the browser.
2
Android Autofill Framework: Hook into Android's native autofill service so the vault can populate passwords directly into apps and mobile browsers.
3
Local PIN / Pattern Unlock: Allow users to set a short device-specific PIN or pattern that leverages the device's secure enclave (TPM/Keystore) to unlock the vault.
4
Clipboard Auto-Clear: Set a timeout (e.g., 60 seconds) to automatically clear the universal clipboard after a password or photo is pasted, preventing accidental leaks.
